# Galgame 搜索

一个界面简洁、可自定义背景的桌面应用，用于在指定网站中查找 galgame，并把搜索结果连同链接一起展示。

## 功能

- 在多个网站中按关键词搜索 galgame，结果带链接，点击在浏览器中打开
- **支持缩写搜索**：
  - 内置常见缩写词典（如 `fsn` → Fate/stay night、`cl` → CLANNAD、`lb` → Little Busters!、`wa2` → WHITE ALBUM 2 等）
  - **通用中文缩写解析**：启动后会在后台下载 shionlib 的 1.4 万个游戏标题建立本地索引，搜“星白”“巧2”这类简写时，自动按“首字 + 顺序字符”匹配出全名，再去各站搜索
  - VNDB 结果按标题/首字母本地重排，让目标作品排在前面
- **支持会社搜索**：搜会社名（如 `柚子社`、`Key`、`型月`、`八月社`、`中二社`）时，软件识别出会社后，会把该社的作品**直接混进每个勾选网站自己的结果里**（shionlib 用本地标题库匹配出中文条目、VNDB 直接附加、Steam 等其他网站逐个搜索校验），不单独分组。内置常见会社别名词典（键社、雪碧社、马戏团、叶子社等），并通过 VNDB 实时解析任意厂商（约 1.4 万家）及其作品
- **导入网址省心**：直接粘贴你在该网站搜过一次后复制出来的网址即可，软件自动识别关键词并替换为 `{keyword}`，无需手写；已添加的网站也可随时点“编辑”修改
- 预置三个网站：VNDB（官方 API）、Steam 商店、书音的图书馆（shionlib，中文档案站）
- 搜索结果按网站分组，**点击分组标题可展开/收起**
- **浅色/深色主题**可切换（默认浅色），**界面透明度**可调
- 自定义背景：本地图片、背景颜色、遮罩深浅均可调


## 运行方式

### 方式一：双击启动脚本

双击 `start.bat`。首次运行会自动安装依赖（需联网），之后直接启动。

### 方式二：命令行

```bash
npm install   # 首次
npm start
```

> 依赖 Node.js。如未安装，请先到 https://nodejs.org/ 下载安装。

## 使用说明

1. 在顶部输入框输入关键词（例如 `CLANNAD`、`FSN`、`白色相簿2`），点击“搜索”。
   - 输入缩写时，界面会提示“已按缩写展开为……”，并自动用全名补搜。
2. 左侧是网站列表：
   - 勾选/取消勾选可启用或停用某个网站。
   - 点击“导入网址”可添加新网站。
   - 点击“恢复默认网站”可还原预置网站。
3. 搜索结果按网站分组，点击任意结果会在浏览器中打开对应链接。
4. 点击右上角“设置背景”可切换浅色/深色主题、调整界面透明度、更换背景图片、颜色和遮罩。

> 说明：首次启动后会在左下角显示“正在加载标题库”的进度条（需联网，约半分钟），完成后自动消失；加载完成前，内置缩写词典（含 星白、巧2 等）仍可正常工作。

## 导入网站说明

在目标网站里**试搜一次**（比如搜 `CLANNAD`），把浏览器地址栏里的网址复制粘贴到“搜索网址”框。软件会：

1. 自动从常见参数（q、search、keyword、wd 等）里识别出示例关键词；
2. 保存时自动把它替换成 `{keyword}` 占位符。

如果识别不出来，也可以手动在“示例关键词”里填写网址中的那个词。若想完全手动控制，直接在网址里写 `{keyword}` 也可以。

- 大多数网站的搜索结果是普通网页，可直接用通用解析（选择器留空即可）。
- 如果通用解析结果不理想，可填写“结果选择器”和“标题选择器”（CSS 选择器）来精确定位结果项。例如某站结果项是 `<a class="result"><span class="title">标题</span></a>`，则结果选择器填 `a.result`，标题选择器填 `.title`。

## 注意事项

- 部分网站会阻止程序抓取（如验证码、登录墙、Cloudflare 防护），对这类网站会显示“抓取失败”，这属于网站限制，并非软件错误。
- 搜索结果仅供学习交流，请遵守目标网站的条款。
- VNDB 使用其官方 API，较稳定；Steam 通过抓取搜索页实现，若页面改版可能需要更新选择器。

## 打包为独立 exe（可选）

```bash
npm run dist   # 生成便携版 exe，输出到 dist/ 目录
```

更换 exe 图标：把 `build\icon.ico` 换成新图标后重新打包；也可用 `node convert-icon.js 图片路径` 一键转换。

## 项目结构

- `main.js`：Electron 主进程（窗口、设置/站点存储、搜索调度）
- `preload.js`：安全的 IPC 桥接
- `search.js`：搜索实现（缩写展开、VNDB API、通用 HTML 解析），可独立测试
- `renderer/`：界面（HTML/CSS/JS，浅色/深色主题）
- `test-search.js`：搜索模块的独立测试脚本（`npm test`）
- `convert-icon.js`：PNG 转多尺寸 ico 的工具脚本
